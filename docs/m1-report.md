## Последовательность операций запуска

source-check (полный хеш источника) → base-copy (копия источника в `base\`, повторно используется при совпадающем отпечатке) → working-copy (`install.wim` в папку запуска) → mount (DISM API, read-write) → registry (загрузка офлайн SOFTWARE `ImageForge_<RunId>_SOFTWARE`, запись `HKLM\SOFTWARE\ImageForge\Validation\Milestone = "M1"` REG_SZ, выгрузка) → unmount-commit → export (`Dism.exe /Export-Image /Compress:max /CheckIntegrity`) → assemble (staging рядом с папкой результата, сверка по манифесту) → source-recheck → publish (атомарная замена через `.previous`).
При любом сбое: образ отключается без сохранения, staging удаляется или возвращается прежний результат, папка запуска удаляется, цель — `NeedsRebuild`.

Замер M1-RUN (запуск из окна): 29 мин 07 с, из них хеширование ≈ 11 мин, DISM ≈ 14 мин.

## Найдено и исправлено во время M1

- Приложение молча падало при старте (`0xC000027B`): без `EnableMsixTooling` не собирался `.pri`. Исправлено; CI запускает опубликованное приложение.
- Сборка результата теряла папку `sources`, если в ней был только `install.wim`. Исправлено с тестом.
- Закрытие окна во время монтирования роняло движок (`DismOpenSessionsException` при `DismApi.Shutdown`). Исправлено: отмена между шагами, хост ждёт окончания операции и очистки.
- Инструкции VM: вывод утилиты не попадал в `Start-Transcript`; `$X` теперь вызывается через `| Out-Host`.
