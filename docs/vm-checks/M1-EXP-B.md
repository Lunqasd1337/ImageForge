# Ручная проверка M1-EXP-B: UAC и канал UI ↔ движок

Статус: **Пройдено** (27.10.2026, сборка `438ba2b`).
Покрывает эксперимент 2 из раздела 16 плана: повышение через UAC, отказ пользователя, проверка сторон соединения и безопасная остановка движка при потере UI.
UAC с вводом учётных данных другого администратора — после M1, отдельным пакетом.

## Сборка

- Артефакт `ImageForge.App-<sha>` из GitHub Actions (джоба «Build all (Windows)»). Внутри: `ImageForge.App.exe`, папка `engine\` с `ImageForge.Engine.Host.exe` и `SHA256.txt`.
- Сборка self-contained: .NET и Windows App SDK ставить не нужно.
- Сверьте хеши обоих exe с `SHA256.txt` (`Get-FileHash <файл> -Algorithm SHA256`).

## Требования

- Та же сервисная VM, что и для M1-EXP-A, или любая Windows 11 x64 VM. Не рабочая Windows хоста.
- Вход под учётной записью **администратора** с включённым UAC (по умолчанию: запрос согласия «Да/Нет»).
- Распакуйте артефакт в `C:\IF\app` (путь без пробелов не обязателен, но так проще сравнивать логи).

Все действия — **в гостевой Windows**.

## Шаги

### 1. Подключение с согласием UAC

1. Запустите `C:\IF\app\ImageForge.App.exe` двойным щелчком (без «Запуск от имени администратора»).
   Ожидается: окно ImageForge; статус «Движок не подключён.»; в «Превью операции» — куст SOFTWARE, ключ `HKLM\SOFTWARE\ImageForge\Validation`, значение `Milestone (REG_SZ) = M1`.
2. Нажмите «Подключить движок». Ожидается: запрос UAC с именем `ImageForge.Engine.Host.exe`. Нажмите «Да».
3. Ожидается в течение нескольких секунд: статус «Движок подключён.», в журнале строка `Движок <версия>, протокол 1, PID <N>, экземпляр <GUID>`.
4. В «Диспетчере задач» → «Подробности» включите столбец «С повышенными правами».
   Ожидается: `ImageForge.App.exe` — «Нет»; `ImageForge.Engine.Host.exe` — «Да», PID совпадает с журналом.

### 2. Закрытие окна останавливает движок

1. Закройте окно ImageForge крестиком.
2. Ожидается: в течение ~5 секунд `ImageForge.Engine.Host.exe` исчезает из «Диспетчера задач».

### 3. Отказ в UAC

1. Снова запустите приложение и нажмите «Подключить движок». В запросе UAC нажмите «Нет».
2. Ожидается: статус «Запуск движка отменён в окне UAC.», приложение продолжает работать, процесса движка нет.
3. Нажмите «Подключить движок» ещё раз и согласитесь. Ожидается: подключение как в шаге 1.3.

### 4. Аварийная потеря UI

1. При подключённом движке завершите `ImageForge.App.exe` через «Диспетчер задач» → «Снять задачу».
2. Ожидается: в течение ~5 секунд `ImageForge.Engine.Host.exe` завершается сам.

### 5. Лог движка

```powershell
Get-ChildItem C:\ProgramData\ImageForge\logs\engine-*.log | Sort-Object LastWriteTime | Select-Object -Last 1 | Get-Content
```
Ожидается: для каждого запуска — `UI process <PID> connected`; после шага 4 — `UI process <PID> exited; stopping engine`; строк `unexpected process` нет.

## Что прислать

«Пройдено» или «Не пройдено» по каждому шагу 1–5 и содержимое лога из шага 5.
При ошибке: номер шага, снимок окна (статус и журнал), сообщение об ошибке, если было.
