# Ручная проверка M1-RUN: запуск из окна приложения

Статус: **Ожидает ручной проверки**.
Покрывает проверки M1 1, 2, 3 и 7 (раздел «Первый рабочий рубеж M1» плана) через настоящий путь UI → RPC → повышенный движок: превью строит движок, запускается ровно показанный план, результат публикуется, исходник не меняется, после запуска нет монтирований и загруженных кустов. Плюс восстановление из окна после прерванного запуска.
Установка результата и вход в WinRE (проверки 4–6) — следующим пакетом.

## Сборка

- Из одной и той же сборки CI этого PR скачайте оба артефакта: `ImageForge.App-<sha>` и `ImageForge.Experiments-<sha>`. Хеши сверьте с их `SHA256.txt`.
- `C:\IF\app` удалите и распакуйте туда новый `ImageForge.App`; `ImageForge.Experiments.exe` положите в `C:\IF` поверх старого.

## Требования

- Та же сервисная VM, фикстура `C:\IF\fixture\media`, рабочая папка `C:\IF\ws` от M1-EXP-C (копия источника в ней используется повторно).
- Нет активных монтирований (`& $X mounts` → `none`), свободно не меньше 20 ГБ.
- Вход под администратором с включённым UAC.

Команды — в PowerShell от администратора, по одной строке:
```powershell
$X = "C:\IF\ImageForge.Experiments.exe"; $M = "C:\IF\fixture\media"; $W = "C:\IF\ws"; $R = "C:\IF\result-ui"
Start-Transcript C:\IF\m1-run.txt
& $X version
& $X manifest $M
```
Ожидается отпечаток источника `A4F26A82…8A2BD352` (F1 из M1-EXP-C).

## Шаги

### 1. Подключение и превью

1. Запустите `C:\IF\app\ImageForge.App.exe` двойным щелчком, нажмите «Подключить движок», в UAC — «Да».
2. Заполните: источник `C:\IF\fixture\media`, рабочая папка `C:\IF\ws`, папка результата `C:\IF\result-ui`. Нажмите «Подготовить».

Ожидается: в журнале строка `Рабочая папка …, цель …`; превью:
```
Куст: офлайн SOFTWARE (Windows\System32\config\SOFTWARE)
Ключ: HKLM\SOFTWARE\ImageForge\Validation
Значение: Milestone (REG_SZ) = M1
```
статус «План готов…», в журнале `План <PlanId>, ревизия <N>, отпечаток …`. Кнопка «Запустить» активна.

### 2. Изменённые папки сбрасывают план

1. В поле папки результата допишите символ и сотрите его. Ожидается: «Запустить» становится неактивной.
2. Нажмите «Подготовить» ещё раз. Ожидается: новый PlanId в журнале, «Запустить» снова активна.

### 3. Неподходящие папки

1. Временно укажите папку результата `C:\IF\fixture\media\out` и нажмите «Подготовить».
   Ожидается: «Папки не подходят: папка результата находится внутри папки «источник»», превью и «Запустить» недоступны.
2. Верните `C:\IF\result-ui` и нажмите «Подготовить».

### 4. Запуск

Нажмите «Запустить» и не закрывайте окно (20–40 минут).
Ожидается: в журнале по ходу строки `source-check...`, `base copy reused`, `mount 25%` … `publish...`; в конце статус «Готово. Результат сохранён.», ссылка `C:\IF\result-ui` открывает папку в проводнике; строка `Итог: None Published …`.

### 5. Сверка результата (PowerShell)

```powershell
& $X manifest $M
& $X mount $R\sources\install.wim 1 C:\IF\mount
& $X read-marker C:\IF\mount
& $X unmount C:\IF\mount discard
& $X mounts
& $X host-check
& $X status $W
```
Ожидается: отпечаток источника снова **F1**; маркер `"M1"`; монтирований нет; на VM маркера нет, загруженных кустов нет; `status` — последний запуск `Published`.

### 6. Прерванный запуск и восстановление из окна

1. В окне нажмите «Подготовить», затем «Запустить». Дождитесь в журнале `mount 50%` (или позже) и **закройте окно** крестиком. Движок остановится сам.
2. `& $X status $W` — ожидается последний запуск `Running` (возможно, с оставшимся монтированием в `C:\IF\ws\mount\…`).
3. Снова запустите приложение, «Подключить движок», те же папки, «Подготовить».
   Ожидается: статус «Предыдущий запуск не завершён. Нажмите «Восстановить»…», «Запустить» недоступна.
4. «Восстановить». Ожидается: строки `Восстановление: discarded mount …` и/или `deleted …`, статус «Восстановление завершено».
5. «Подготовить» → «Запустить» → «Готово». Затем `& $X mounts` → `none`, `& $X manifest $M` → **F1**.

Если на шаге 6.1 окно закрылось не сразу или движок не остановился в течение минуты — это тоже результат, напишите.

### 7. Лог движка

```powershell
Get-ChildItem C:\ProgramData\ImageForge\logs\engine-*.log | Sort-Object LastWriteTime | Select-Object -Last 1 | Get-Content -Tail 60
Stop-Transcript
```
Ожидается: строки `plan <PlanId>` и `start plan <тот же PlanId>` для каждого запуска, `run …: rejection None, status Published`.

## Что прислать

«Пройдено» / «Не пройдено» по шагам 1–7, `C:\IF\m1-run.txt`, текст журнала из окна (можно выделить и скопировать) и вывод шага 7.
При ошибке — снимок окна и `%LOCALAPPDATA%\ImageForge\logs\app-crash.log`, если он появился. Оставшиеся монтирования не очищайте сами.
